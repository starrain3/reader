# 隨身小說閱讀器 (Ku Novel Reader)

專為 Android 行動裝置打造的高質感小說閱讀器，支援現代 PWA（一鍵加到主畫面全螢幕運作）與 Capacitor 原生 APK 封裝雙模架構。

---

## ✨ 核心特色與功能

1. **極致手機觸控閱讀手感**：
   - 專為單手與觸控優化：左側 25% 點擊上一頁/滾動、右側 25% 點擊下一頁/滾動、中央 50% 呼叫沉浸控制列。
   - 仿真翻頁進度條、快速章節跳轉滑桿。
   - 5 大閱讀主題配色：象牙純白、護眼豆沙綠、復古暖黃羊皮紙、典雅暗灰、純黑（AMOLED 極致省電）。
   - 字體大小（A- / A+）、自訂行距。
   - 底部常駐閱讀狀態列（章節標題、系統時鐘）。

2. **跨書源線上搜尋與即時爬取**：
   - 內建小說狂人 (CZBooks)、筆趣閣 (Biquge)、69書吧 (69shu) 等熱門書源。
   - 智慧書源規則引擎（基於 CSS Selector 與正則表達式，支援在 UI 中自由新增、編輯、匯入與匯出 JSON 書源規則）。
   - 支援線上搜尋、查看小說詳情、目錄大綱解析、一鍵加入書架或立即閱讀。
   - 自動過濾常見網站廣告、浮水印與導流文字。

3. **雙重網路請求適配層 (Zero-CORS Ready)**：
   - **PWA 模式**：支援 Cloudflare Worker 免費代理或公共代理轉發，繞過手機瀏覽器跨域限制。
   - **原生 APK 模式**：啟用 `CapacitorHttp` 原生網路請求，在手機底層直連目標小說站，完全無需任何代理伺服器！

4. **離線閱讀與資料庫儲存 (IndexedDB)**：
   - 整本書加入書架後，章節自動背景預加載（閱讀當前章時，自動在背景快取下一章，切章零等待）。
   - 支援出門完全無網路（飛航模式）下離線閱讀已下載章節。
   - 自動記憶每本書的最後閱讀章節與閱讀歷史。

5. **本地書籍匯入 (TXT & EPUB)**：
   - **TXT 檔案**：自動偵測 UTF-8、Big5、GBK 編碼，支援數十種中文章節正規劃分規則，自動切分目錄章節。
   - **EPUB 檔案**：支援解構 EPUB 容器、解析目錄與排版內文。

6. **閱讀輔助工具**：
   - **一鍵繁簡轉換 (OpenCC)**：解決簡體起點/筆趣閣小說的字體閱讀習慣問題，智慧轉為台灣繁體習慣用語。
   - **TTS 語音朗讀**：整合 Web Speech API，自動挑選台灣國語/中文語音，具備分段防中斷、語速調節（0.5x ~ 2.5x）與自動章節接續朗讀。

## 🚀 本地開發與手機即時預覽

1. **啟動本機伺服器**：
   ```bash
   npm run dev
   ```
2. **在手機上預覽**：
   - 確認手機與電腦連線同一個 Wi-Fi 網路。
   - 終端機將會顯示您的區網 IP 網址（例如 `http://192.168.1.100:5173/`）。
   - 用 Android 手機的 Chrome 瀏覽器開啟該網址即可立即體驗！

---

## 📱 如何在 Android 手機上如同 App 使用？ (PWA 安裝)

1. 用手機的 **Chrome 瀏覽器** 開啟閱讀器網址。
2. 點擊瀏覽器右上角的「**⋮**」（更多選單）。
3. 點選「**加到主畫面**」或「**安裝應用程式**」。
4. 手機桌面將會出現專屬的 App 圖示，打開後享有獨立全螢幕、無瀏覽器網址列、完整的 App 手感！

---

## 📦 如何打包成 Android 獨立安裝檔 (.apk)？

專案已內建 `.github/workflows/build-apk.yml` 與 `capacitor.config.json`：

1. 將本專案推送到您的 GitHub 儲存庫。
2. 進入 GitHub 專案頁面中的 **Actions** 分頁。
3. 系統將會自動啟動免費的 Ubuntu 雲端環境，自動建置 Web 資源並編譯出 `app-debug.apk`。
4. 在 Actions 頁面的 **Artifacts** 區塊直接下載 APK 檔案安裝到手機即可！
